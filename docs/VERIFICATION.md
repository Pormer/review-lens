## 알려진 범위

무료 공개 검색·접근 가능한 페이지의 부분 근거 분석, 로컬 AI 상품 일치/감성 추정, 단일 인스턴스·단일 worker, 공유 접근 키 기반의 소규모 서비스입니다. 전체 쇼핑몰 리뷰 수집·사실의 독립 검증·사용자별 권한 분리·다중 worker는 포함되지 않습니다. Render 무료 설정은 모델 없는 예제 평가용입니다.

## 수집 개선 보류 및 다음 단계

2026-09-14 사용자 요청에 따라 쇼핑몰별 원문 수집 확장 작업은 보류합니다. 현재의 접근 제한 안내는 robots 정책·HTTP 실패·빈 본문·시간 제한 등 여러 원인을 포함하므로, 모두 사이트의 차단이라고 단정하지 않습니다. 검색과 접근 가능한 공개 사용기를 활용하는 범위로 진행하며, 원문을 확보하지 못한 자료가 있다는 사실은 리포트에 계속 표시합니다.

다음 단계는 배포 방식 확정입니다. 현재 Ollama 분석은 로컬 PC에서 유지합니다. 기존 Render 설정은 실제 모델이 없는 가상 예제 평가용이며, 이를 실제 상품 분석 서비스의 공개 배포 완료로 표시하지 않습니다. 공개 예제 배포 여부는 사용자 선택 대기 중입니다. OpenAI는 검증 완료 여부와 관계없이 사용자가 명시적으로 요청할 때만 전환합니다.
