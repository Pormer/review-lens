# 트러블슈팅

## Python 실행 시 다른 버전이 나옵니다

Windows의 `python`이 3.9를 가리킬 수 있습니다. `py -0p`로 설치 목록을 확인하고 `py -3.12 -m venv .venv`로 생성합니다. 이후에는 `.venv\Scripts\python.exe`를 명시합니다. 이 프로젝트는 `| None` 타입 등 Python 3.12 기준으로 작성했습니다.

## 가상환경 생성이나 pip 설치에서 Permission denied

이번 개발 환경에서는 샌드박스의 임시 폴더 권한 때문에 `ensurepip`, pip 압축 해제와 pytest 임시 폴더 생성이 실패했습니다. 일반 터미널에서 프로젝트 폴더를 열고 같은 명령을 실행하거나 도구가 요청하는 해당 명령의 권한을 허용하면 됩니다. 시스템 전체 권한이나 보안 설정을 해제할 필요는 없습니다.

## 화면은 뜨지만 실제 분석이 안 됩니다

기본 모드는 Ollama입니다. Ollama가 실행 중인지, `ollama list`에 `OLLAMA_MODEL`이 존재하는지 확인하고 페이지를 새로고침합니다. API 키는 필요 없습니다. 환경 변수 변경 시 서버를 재시작합니다. `APP_ENV=production`이라면 `APP_ACCESS_KEY`가 최소 24자여야 합니다. `AI_PROVIDER=openai`를 직접 선택한 경우에만 서버의 `OPENAI_API_KEY`를 확인합니다.

## 401 / 인증 실패

HTTP 401은 웹에서 입력한 서비스 접근 키가 잘못된 경우입니다. 설정에서 수정하세요. 접수된 작업이 ‘분석 서비스 인증 실패’로 종료되면 서버의 OpenAI API 키 문제입니다. 두 키는 용도가 다릅니다.

## 429 / 한도 초과

서버는 실제 분석 기본 시간당 10건, 최대 대기 8건을 허용합니다. 예제 포함 총 접수도 기본 100건/시간으로 제한합니다. 서버 한도는 전체 사용자 공유입니다. 외부 OpenAI 계정 한도에 걸리면 접수 후 작업이 실패할 수 있습니다. 서비스 사용 한도와 프로젝트 예산을 확인합니다. 리포트를 삭제해도 호출량 기록은 한 시간 유지됩니다.

## 출처가 적거나 별점·괴리 값이 ‘—’입니다

접근 제한, 로그인, 검색 노출 부족 또는 모델명이 불명확한 경우일 수 있습니다. 모델 번호·세대를 정확히 입력하고 유효한 공개 상품 링크인지 확인합니다. 개별 리뷰의 별점과 본문을 함께 확보하지 못하면 평균을 만들지 않습니다. 3건 미만이면 괴리 비율도 숨깁니다. 없는 데이터를 임의로 채우지 않는 정상 동작입니다.

## 검색됐는데 일부 근거가 사라집니다

다른 모델·옵션, 불명확한 일치 여부, 중복 본문, 연구 메모에 없는 발췌, 없는 출처 ID는 제외합니다. 보고서의 제외 건수와 한계를 확인하세요. ‘후보 출처’ 수와 실제 사용 출처 수는 다를 수 있습니다.

## 분석이 오래 걸리거나 중단됩니다

기본 전체 제한은 600초입니다. 네트워크나 로컬 모델 속도에 따라 실패할 수 있습니다. 필요하면 `JOB_TIMEOUT_SECONDS`를 10~1800 사이에서 조정합니다. 작은 로컬 모델이 형식을 지키지 못하면 일부 근거를 제외합니다. 더 큰 모델은 품질과 자원 사용 사이의 선택입니다. 서버가 재시작되면 진행 중 작업은 실패로 표시되고 자동 재실행하지 않습니다.

## 새로고침 후 기록이 없습니다

이 브라우저가 기억하는 작업 ID 목록은 localStorage에, 실제 리포트는 서버 SQLite에 있습니다. 다른 브라우저·시크릿 모드에서는 목록이 공유되지 않습니다. 완료 리포트의 `#report=UUID` 주소로 다시 열 수 있지만 서비스 접근 키가 설정되어 있다면 동일 키가 필요합니다. 기본 보관 기간이 지난 기록은 조회할 수 없습니다.

## Render에서 재배포 후 기록이 사라집니다

무료 플랜의 로컬 파일은 영구 저장이 아닙니다. 운영용 디스크 또는 외부 데이터베이스가 필요합니다. [배포 가이드](DEPLOYMENT.md)를 참고하세요.

## 8000 포트를 사용할 수 없습니다

다른 서버가 실행 중인지 확인하거나 `--port 8001`로 시작해 [localhost:8001](http://localhost:8001)에 접속합니다. 프런트엔드는 상대 경로로 API를 호출하므로 별도 URL 변경은 필요 없습니다.

## 테스트의 외부 라이브러리 경고

검증 환경의 Starlette는 httpx 기반 TestClient와 AnyIO BlockingPortal 별칭에 대해 deprecation 경고를 표시했습니다. 기능 테스트는 통과했습니다. 잠금 파일 업데이트 시 FastAPI·Starlette·HTTP 클라이언트를 함께 검증해 변경해야 합니다.
