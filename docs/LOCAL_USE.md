# 로컬 버전 사용 안내

현재 PC에는 리뷰렌즈, Ollama, `qwen2.5:3b` 모델이 설치되어 있습니다. 공개 배포는 보류했으며 네이버 키나 OpenAI 키를 발급받을 필요가 없습니다.

## 지금 사용하기

1. [리뷰렌즈 열기](http://127.0.0.1:8000)를 누릅니다.
2. 정확한 상품명과 모델 번호, 공개 구매 링크 하나를 입력하고 분석을 시작합니다.
3. 결과의 수집 수치와 근거·출처를 확인합니다. 보관할 결과는 Markdown 또는 JSON으로 내려받습니다. 서버의 기본 보관 기간은 7일입니다.

현재 주소는 이 PC에서만 접속하는 주소입니다. GitHub와 블로그 링크는 다른 사람에게 공유할 수 있지만 이 주소를 보내도 다른 사람의 PC에서 같은 서버에 접속할 수는 없습니다.

## PC를 다시 켠 뒤 실행하기

1. 시작 메뉴에서 **Ollama**를 실행합니다. 이미 실행 중이면 다시 실행할 필요가 없습니다.
2. PowerShell에서 다음 명령을 실행합니다. 기존 설치를 사용하므로 매번 모델이나 패키지를 다시 설치하지 않습니다.

```powershell
Set-Location -LiteralPath '..\Review_Service'
& '.\.venv\Scripts\python.exe' -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers
```

3. [리뷰렌즈](http://127.0.0.1:8000)를 열어 **로컬 AI 준비됨** 표시를 확인합니다.

서버를 실행한 PowerShell 창은 사용하는 동안 열어 둡니다. 이미 사이트가 정상적으로 열리면 서버를 중복 실행하지 않습니다. 8000 포트 사용 중 오류가 나면 먼저 기존 사이트가 열리는지 확인합니다.

## 사용을 마쳤을 때

분석이 끝난 뒤 직접 서버를 실행한 PowerShell 창에서 `Ctrl+C`를 누르면 서버가 종료됩니다. 브라우저 탭만 닫는 것은 서버 종료가 아닙니다. Ollama도 사용하지 않을 때는 종료할 수 있습니다. PC를 24시간 켜 둘 필요는 없으며, 실행 중 분석은 PC 종료·절전 시 중단될 수 있습니다.

## 결과를 볼 때

- 원문 수집 실패 안내는 접근 정책, HTTP 오류, 빈 본문, 시간 초과 등 여러 이유를 포함합니다. 모든 쇼핑몰 리뷰를 수집한 결과가 아닙니다.
- 출처가 있어도 로컬 모델이 상품·자료 유형을 잘못 분류하거나 요약에서 원문보다 강한 결론을 낼 수 있습니다. 원문 발췌와 출처를 함께 검토합니다.
- 별점과 해당 리뷰 본문을 함께 확보하지 못하면 별점·괴리 수치는 표시하지 않습니다.
- 오래된 리포트는 코드 수정 후에도 자동 재분석되지 않습니다. 바뀐 기능은 새 분석에 적용됩니다.

Ollama 또는 수집이 실패해도 OpenAI로 자동 전환하지 않습니다. 모델·배포 방식 변경은 추후 사용자가 요청할 때 별도로 진행합니다.
